# Power BI Portfolio

Hi, I'm Mohamed — this repo collects the Power BI projects I'm building while learning data visualization and dashboard design. Each project folder has the dataset, the .pbix file, and a written breakdown of what I found.

## Projects
### [Data Professional Survey Dashboard](./data-professional-survey-dashboard)

Built a multi-page dashboard in Power BI analyzing survey responses from 630 data professionals — salary by job title and gender, participant demographics by country and programming language, and job satisfaction ratings, using treemaps, bar charts, and gauges.

## Tools & Skills
- Power BI: DAX measures, treemaps, gauges, filters/slicers
- Data visualization: dashboard layout, theming, chart selection
